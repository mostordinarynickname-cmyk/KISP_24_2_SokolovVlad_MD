# Введение в JavaScript

**JavaScript (JS)** — изначально создавался, чтобы «сделать веб-страницы живыми». Скрипты работают как простой текст без компиляции и не имеют отношения к Java.

###  Движки (Виртуальные машины)
JS выполняется специальной программой — движком (в браузере или на сервере).
- **V8** — Chrome, Opera, Edge.
- **SpiderMonkey** — Firefox.
- **Схема работы:** Чтение (парсинг) ➡️ Компиляция в машинный код ➡️ Запуск и оптимизация.

###  Возможности в браузере (Безопасный язык)
- **Можно:** изменять HTML/CSS, реагировать на клики/мышь, отправлять сетевые запросы (AJAX), работать с куками и `localStorage`.
- **Нельзя (ради безопасности):** 
  - Читать/писать файлы на жестком диске (без выбора пользователем).
  - Получать доступ к другим вкладкам/окнам разных сайтов (*Политика одинакового источника / Same Origin Policy*).
  - Управлять камерой/микрофоном без явного разрешения.

###  Уникальность JS
Единственная браузерная технология, которая объединяет:
1. Полную интеграцию с **HTML/CSS**.
2. Простоту реализации базовых вещей.
3. Поддержку **всеми браузерами** по умолчанию.

###  Языки «над» JavaScript (Транспиляция)
Код сторонних языков конвертируется в JS перед запуском в браузере:
- **TypeScript** (от Microsoft) и **Flow** (от Facebook) — добавляют строгую типизацию для больших систем.
- **CoffeeScript** — синтаксический сахар для лаконичности.
- **Dart** (от Google) — язык для мобильных приложений и веба.
- **Brython** — транспилирует Python в JS.

# Справочники и спецификации JS

###  Спецификация (ECMA-262)
- **Суть:** Официальный стандарт, определяющий язык JavaScript. Источник самой достоверной информации.
- **Черновик стандарта:** [tc39.es/ecma262](https://tc39.es/ecma262/) (обновляется ежегодно).
- **Новые фичи (Stage 3):** Предложения, которые скоро войдут в стандарт, находятся на [github.com/tc39/proposals](https://github.com/tc39/proposals).

###  Справочники
- **MDN (Mozilla):** Главный ежедневный справочник с примерами (функции, методы, объекты).
- **Лайфхак поиска:** Искать в Google через префикс `MDN [запрос]` (например, `MDN parseInt`).

###  Таблицы совместимости
Помогают узнать, какие возможности языка уже поддерживаются браузерами и движками:
- [caniuse.com](https://caniuse.com) — поддержка фич по отдельности (включая криптографию, HTML/CSS).
- [kangax.github.io/compat-table](https://kangax.github.io/compat-table) — огромная детальная таблица соответствия стандартам (ES6, ES2016+).

# Редакторы кода: Главное

Программисты используют два типа инструментов: **IDE** и **«лёгкие» редакторы**. Многие совмещают оба варианта.

## 1. IDE (Интегрированная среда разработки)
Работает на уровне **всего проекта** (загружает много данных, видит связи между всеми файлами). Includes автодополнение, Git, тесты.

* **Visual Studio Code** — кросс-платформенная, бесплатная.
* **WebStorm** — кросс-платформенная, бесплатная для некоммерческого использования.
* **Visual Studio** — мощная, платная (есть бесплатная версия Community), только для Windows. Отлично подходит для .NET.

## 2. «Лёгкие» редакторы
Менее мощные, но **очень быстрые**. Нужны для того, чтобы моментально открыть и отредактировать один файл. Границы размыты из-за плагинов.

* **Sublime Text** — кроссплатформенный, условно-бесплатный.
* **Notepad++** — только для Windows, бесплатный.
* **Vim / Emacs** — хорошие консольные варианты для тех, кто умеет ими пользоваться.

> **Итог:** Выбор индивидуален. Выбирайте инструмент под свои привычки, задачи и личные предпочтения.

# Консоль разработчика: Главное

Браузер по умолчанию скрывает ошибки в коде. Чтобы их увидеть и починить, используются встроенные **Инструменты разработки** (Developer tools или **DevTools**). Популярные лидеры среди программистов — **Chrome** и **Firefox**.

## Что можно делать в консоли
* **Смотреть ошибки** — они подсвечиваются красным цветом.
* **Искать место поломки** — справа от ошибки указана ссылка на файл и номер строки кода.
* **Запускать JS-команды** — писать код в строке после символа `>`.
* **Многострочный ввод** — чтобы перенести строку без запуска кода, используйте **Shift + Enter**.

## Как открыть DevTools

| Браузер | Windows / Linux | macOS | Особые условия |
| :--- | :--- | :--- | :--- |
| **Chrome / Firefox / Edge** | `F12` | `Cmd + Opt + J` | Открывается сразу |
| **Safari** | Не поддерживается | `Cmd + Opt + C` | Нужно включить чекбокс в *Настройки -> Продвинутые -> Показывать меню «Разработка»* |

> **Итог:** DevTools во всех браузерах работают примерно одинаково. Они позволяют находить ошибки, проверять переменные и выполнять JavaScript «на лету».

# Привет, мир!: Главное

Для изучения самого языка JavaScript нужна среда запуска. В учебнике используется **браузер** (это проще для онлайн-примеров), но на сервере скрипты запускаются иначе (например, командой `node my.js`).

## Тег <script>
Код JavaScript вставляется в любое место HTML-документа с помощью тега `<script>`. Браузер выполняет его автоматически.

```html
<script>
  alert('Привет, мир!');
</script>
```

### Устаревшая разметка (не использовать в новом коде)
* **Атрибут `type="..."`** (раньше писали `type="text/javascript"`). Сейчас не нужен. В современном HTML применяется только для модулей.
* **Атрибут `language="..."`**. Устарел, так как JavaScript является языком по умолчанию.
* **HTML-комментарии внутри скрипта** (`<!-- ... //-->`). Использовались 15+ лет назад для древних браузеров. Сейчас это признак старого кода.

## Внешние скрипты
Большой и сложный код выносят в отдельные `.js` файлы и подключают через атрибут `src`:

```html
<!-- Абсолютный или относительный путь -->
<script src="/js/script1.js"></script> 
<!-- Полный URL-адрес из сети -->
<script src="https://cloudflare.com"></script> 
```

### Плюсы внешних файлов
* **Кеширование** — браузер скачивает файл один раз и сохраняет его у себя. 
* **Скорость** — при переходе на другие страницы скрипт берется из кеша, что экономит трафик и ускоряет загрузку сайта.

### Важное ограничение
>  **Нельзя совмещать код и атрибут `src` в одном теге!** Код внутри тега будет полностью проигнорирован.

* **Не работает:**
  ```html
  <script src="file.js"> alert(1); </script>
  ```
* **Правильно (разбить на два тега):**
  ```html
  <script src="file.js"></script>
  <script> alert(1); </script>
  ```

> **Итог:** JS подключается тегом `<script>`. Внутрь пишется простой код, а для сложного используется `<script src="путь_к_файлу.js">`.

# Структура кода: Главное

Код на JavaScript состоит из инструкций и комментариев. Они определяют логику работы программы и помогают разработчикам понимать её структуру.

## 1. Инструкции
**Инструкции** — это команды, которые выполняют действия (например, `alert('Привет')`). 

* Каждую инструкцию принято писать на **новой строке**, чтобы код было легче читать.
* Инструкции разделяются **точкой с запятой** (`;`).

## 2. Точка с запятой и её автоматическая вставка
В большинстве случаев точку с запятой в конце строки можно опустить. JavaScript понимает перенос строки как «неявную» точку с запятой. 

### Когда перенос строки НЕ вставляет точку с запятой:
1. **Строка не завершена:** Если строка заканчивается на оператор (например, `+`), движок понимает, что выражение продолжается на следующей строке.
   ```javascript
   alert(3 +
   1
   + 2); // Выведет 6
   ```
2. **Опасные ситуации (ошибки):** Иногда JavaScript «забывает» поставить точку с запятой, что приводит к критическим ошибкам. Чаще всего это происходит перед квадратными скобками `[...]`.

* **Код с ошибкой:**
  ```javascript
  alert("Hello")
  [1, 2].forEach(alert);
  ```
  *Почему ломается?* Движок не ставит тут точку с запятой и видит это как одну строку: `alert('Hello')[1, 2].forEach(alert);`.

>  **Правило сообщества:** Всегда ставьте точку с запятой между инструкциями. Это безопаснее и защищает от труднонаходимых ошибок.

## 3. Комментарии
Комментарии нужны для описания кода. Движок JavaScript полностью игнорирует их при выполнении.

* **Однострочные:** Начинаются с `//`. Комментарием становится всё, что идет после этих символов до конца строки.
  ```javascript
  // Это отдельный комментарий
  alert('Привет'); // Это комментарий после инструкции
  ```
* **Многострочные:** Начинаются с `/*` и заканчиваются `*/`.
  ```javascript
  /* Этот код временно отключен
  alert('Привет');
  */
  ```

### Важные нюансы о комментариях
* **Вложенные комментарии запрещены!** Код вида `/* ... /* ... */ ... */` вызовет ошибку.
* **Горячие клавиши:** Для быстрой вставки используйте `Ctrl + /` (Windows) или `Cmd + /` (Mac).
* **Размер кода:** Комментарии не раздувают итоговый сайт. Перед выкатом на сервер специальные инструменты (минификаторы) автоматически удаляют их из кода.

> **Итог:** Пишите каждую инструкцию с новой строки, обязательно ставьте `;` в конце и не стесняйтесь оставлять комментарии для пояснения сложной логики.

# Строгий режим — "use strict": Главное

До 2009 года JavaScript развивался с полной обратной совместимостью, из-за чего в языке копились старые ошибки проектирования. В стандарте ECMAScript 5 (ES5) появились изменения, которые могли сломать старый код. Чтобы этого не произошло, новые правила сделали отключаемыми. Для их активации используется директива `"use strict"`.

## Директива «use strict»
Строка `"use strict";` (или `'use strict';`) переводит интерпретатор JavaScript в современный режим работы, где исправлены некоторые системные ошибки и действуют более строгие правила написания кода.

* **Где размещать:** Только в самом начале скрипта или в начале тела функции (для локального включения).
* **Над директивой** могут находиться исключительно комментарии. Любой исполняемый код перед ней аннулирует её действие.

Неправильно (строгий режим не включится):
```javascript
alert("Некоторый код");
"use strict"; 
// Директива проигнорирована, так как она не на первой строке
```

* **Необратимость:** Строгий режим нельзя отключить внутри скрипта. Директивы вроде "no use strict" не существует.

## Работа в консоли браузера
В консоли DevTools строгий режим по умолчанию выключен. Чтобы запустить код в строгом режиме, используйте перенос строки:

```javascript
'use strict'; // Нажмите Shift+Enter для переноса
// ...ваш код... // Нажмите Enter для запуска
```

Для старых браузеров используется обёртка в функцию:
```javascript
(function() {
  'use strict';
  // ...ваш код...
})();
```

## Всегда ли нужно писать «use strict»?
В современном JavaScript писать директиву вручную нужно не всегда:

* **Классы и модули** (продвинутые структуры языка) включают строгий режим автоматически по стандарту.
* **В обычном коде** (без классов/модулей) добавлять `"use strict";` в начало файлов по-прежнему обязательно.

> Итог: На этапе изучения языка всегда добавляйте `"use strict";` на первую строку своих скриптов, чтобы сразу писать качественный код без устаревших багов.

# Переменные и константы: Главное

Переменная — это именованное хранилище для данных в памяти компьютера. Она позволяет структурировать информацию в приложении.

## 1. Объявление и использование переменных
Для работы с переменными используются ключевые слова `let`, `const` и устаревшее `var`.

* **Ключевое слово `let`** — современный стандарт объявления изменяемых переменных.
  ```javascript
  let message = 'Hello!'; // Объявили переменную и записали значение
  message = 'World!';     // Значение изменено, старое удалено
  ```
* **Правило хорошего тона:** Объявляйте каждую переменную на новой строке. Варианты записи нескольких переменных через запятую в одну или несколько строк технически работают, но ухудшают читаемость.
* **Запрет повторного объявления:** Переменную с одним и тем же именем можно объявить через `let` только один раз. Повторный вызов `let message` вызовет ошибку `SyntaxError`.
* **Устаревшее ключевое слово `var`:** Почти то же самое, что и `let`, но объявляет переменные специфическим старым способом. В современном коде не используется.

### Присвоение без объявления
В старом JavaScript без использования `"use strict"` можно было создать переменную, просто присвоив ей значение (`num = 5`). В строгом режиме такой код вызовет ошибку `ReferenceError: num is not defined`.

## 2. Константы (`const`)
Если переменная не должна меняться, её объявляют с помощью ключевого слова `const`. Попытка перезаписать константу приведет к ошибке.

Разработчики разделяют константы на два типа по способу их именования:
1. **Константы времени компиляции (жесткие):** Их значения известны **до запуска** скрипта. Используются как псевдонимы для «жестко закодированных» значений. Пишутся **ЗАГЛАВНЫМИ_БУКВАМИ** через подчеркивание.
   ```javascript
   const COLOR_RED = "#F00";
   const COLOR_ORANGE = "#FF7F00";
   ```
2. **Константы времени выполнения:** Их значения вычисляются **в процессе работы** программы, но после этого больше не изменяются. Пишутся в стандартном **camelCase**.
   ```javascript
   const pageLoadTime = /* время загрузки страницы */;
   ```

## 3. Правила именования переменных
Правильный выбор имен — один из важнейших навыков разработчика. 

* **Ограничения языка:**
  * Разрешены только буквы, цифры, а также символы `$` и `_`.
  * Имя не может начинаться с цифры.
  * Нельзя использовать зарезервированные слова (`let`, `class`, `return`, `function`).
* **Регистрозависимость:** Переменные `apple` и `APPLE` — это две абсолютно разные переменные.
* **Язык и стиль:** Используется международный стандарт — английский язык и верблюжья нотация (`userName`, `shoppingCart`). Использование кириллицы разрешено технически, но не рекомендуется.

### Рекомендации по выбору имен:
* Делайте имена максимально описательными и лаконичными. 
* Избегайте бесполезных имен вроде `data` и `value`, а также коротких букв `a`, `b`, `c` (за редкими исключениями).
* Договаривайтесь с командой о терминах (если пользователь — это `user`, то пишите `currentUser`, а не `currentVisitor`).

## 4. Создание новых переменных против повторного использования
Нельзя использовать одну и ту же переменную для хранения совершенно разных по смыслу данных ради мнимой экономии. 

* Повторное использование переменных запутывает код и усложняет отладку.
* Дополнительная переменная — это польза. Современные браузеры и минификаторы отлично оптимизируют код, поэтому разделение данных по разным переменным никак не вредит производительности и даже помогает движку оптимизировать вычисления.

> Итог: 
> * `let` — для изменяемых данных, `const` — для неизменяемых.
> * Имена должны быть понятными, на английском языке, в стиле camelCase.
> * Под каждую новую задачу создавайте новую переменную.

# Типы данных: Главное

JavaScript является **динамически типизированным** языком программирования. Типы данных привязаны к самим значениям, а не к переменным. Одна и та же переменная может сначала хранить строку, а затем — число.

Всего в JavaScript существует **8 основных типов данных**: 7 примитивных и 1 сложный (объект).

---

## 1. Число (number)
Представляет как целые числа, так и числа с плавающей точкой (десятичные дроби).

* **Специальные числовые значения:**
  * `Infinity` — математическая бесконечность (∞). Она больше любого числа. Можно получить, например, при делении на ноль (`1 / 0`).
  * `-Infinity` — отрицательная бесконечность.
  * `NaN` (Not a Number) — вычислительная ошибка. Возникает при выполнении математически некорректной операции (например, `"не число" / 2`).

* **Свойства NaN и безопасность:**
  * **«Прилипчивость»:** Любая математическая операция с участием `NaN` всегда возвращает `NaN` (например, `NaN + 1`). Единственное исключение: `NaN ** 0` равно `1`.
  * **Безопасность вычислений:** Математика в JavaScript безопасна. Скрипт никогда не упадет с критической ошибкой из-за неверных расчетов. В худшем случае программа вернет `NaN`.

---

## 2. BigInt
Обычный тип `number` не может безопасно хранить целые числа за пределами диапазона от -(2⁵³-1) до (2⁵³-1). За этими границами JavaScript теряет точность.

* **Назначение:** `BigInt` нужен для работы с целыми числами произвольной длины без ограничений (используется в криптографии или точных таймстампах).
* **Создание:** Чтобы указать, что число относится к типу `BigInt`, в самый конец числового литерала добавляется символ `n`.
  ```javascript
  const bigInt = 1234567890123456789012345678901234567890n;
  ```
* **Поддержка:** Работает во всех современных браузерах, кроме устаревшего Internet Explorer.

---

## 3. Строка (string)
Текстовые данные всегда оборачиваются в кавычки одного из трех видов:

1. Двойные кавычки: `"Привет"`.
2. Одинарные кавычки: `'Привет'` (ничем не отличаются от двойных).
3. Обратные кавычки (бектики): \`Привет\` (обладают расширенными возможностями).

* **Особенность обратных кавычек:** Позволяют встраивать переменные и любые математические выражения внутрь строки с помощью конструкции `${...}`.
  ```javascript
  let name = "Иван";
  alert( `Привет, ${name}!` ); // Выведет: Привет, Иван!
  alert( `Результат: ${1 + 2}` ); // Выведет: Результат: 3
  ```
  Обычные кавычки такую функциональность не поддерживают.

* **Важно:** В JavaScript нет отдельного типа данных для одного одиночного символа (типа `char`). Любой текст относится исключительно к типу `string`.

---

## 4. Булевый тип (boolean)
Логический тип данных, который имеет всего два возможных значения:
* `true` — истина (да).
* `false` — ложь (нет).

Используется для хранения флагов состояния или результатов сравнения (`let isGreater = 4 > 1;`).

---

## 5. Значение «null»
Специальное значение, которое образует свой собственный отдельный тип.
* **Смысл:** В JavaScript `null` не является ссылкой на несуществующий объект. Это просто маркер, обозначающий «ничего», «пусто» или «значение неизвестно».
  ```javascript
  let age = null; // Возраст пока неизвестен
  ```

---

## 6. Значение «undefined»
Также образует свой собственный отдельный тип.
* **Смысл:** Означает, что «значение переменной не было присвоено». Если переменная просто объявлена через `let`, но в неё ничего не записали, её значением автоматически становится `undefined`.
  ```javascript
  let age;
  alert(age); // Выведет "undefined"
  ```
* **Рекомендация:** Не стоит вручную присваивать `age = undefined`. Для явного обнуления переменной всегда используйте `null`.

---

## 7. Объекты (object)
Этот тип данных стоит особняком. Все предыдущие типы называют **«примитивными»**, так как они хранят только одно простое значение. Внутри объектов хранятся **коллекции данных** и сложные комплексные структуры.

---

## 8. Символы (symbol)
Используется для создания уникальных идентификаторов внутри объектов.

---

## Оператор typeof
Используется для проверки того, какой тип данных находится внутри переменной. Возвращает результат в виде строки.

* **Синтаксис:** Может использоваться как обычный оператор (`typeof x`) или в форме функции (`typeof(x)`).
* **Приоритет:** Имеет очень высокий приоритет. При проверке выражений обязательны скобки, иначе проверится только первый элемент: `typeof (50 + " Квартир")`.

* **Результаты вызовов:**
  ```javascript
  typeof undefined   // "undefined"
  typeof 0           // "number"
  typeof 10n         // "bigint"
  typeof true        // "boolean"
  typeof "foo"       // "string"
  typeof Symbol("id")// "symbol"
  typeof Math        // "object"   (встроенный объект)
  typeof null        // "object"   (историческая ошибка в языке)
  typeof alert       // "function" (функции технически объекты, но выделяются)
  ```

* **Важные нюансы typeof:**
  1. `typeof null` возвращает `"object"` — это признанная ошибка в самом JavaScript, допущенная при его создании. Её оставили ради обратной совместимости. На самом деле `null` — это отдельный примитивный тип.
  2. `typeof alert` возвращает `"function"` — отдельных типов для функций нет (они являются разновидностью объектов), но оператор обрабатывает их по-особенному для удобства.

  # Взаимодействие: alert, prompt, confirm: Главное

Для взаимодействия с пользователем в браузере используются три встроенные функции: `alert`, `prompt` и `confirm`. 

Все они вызывают **модальные окна**. Это означает, что пока окно открыто, пользователь полностью заблокирован: он не может кликать по странице, нажимать кнопки или взаимодействовать с остальным интерфейсом сайта. Выполнение скрипта на это время также приостанавливается.

---

## 1. alert
Просто выводит информационное сообщение на экран и останавливает работу, пока пользователь не нажмет «ОК».

```javascript
alert("Hello");
```

---

## 2. prompt
Используется для получения текстовых данных от пользователя.

* **Синтаксис:** `result = prompt(title, [default]);`
  * `title` — текст вопроса, отображаемый в окне.
  * `default` — необязательный второй параметр, который задает начальное значение в поле ввода. Квадратные скобки `[...]` в документации всегда указывают на факультативность параметра.
* **Что возвращает:**
  * **Строку** с тем текстом, который ввел пользователь (если нажата кнопка «ОК»).
  * **`null`**, если пользователь отменил ввод (нажал кнопку «Отмена» или клавишу `Esc`).

```javascript
let age = prompt('Сколько тебе лет?', 100);
alert(`Тебе ${age} лет!`); // Выведет значение, либо null при отмене
```

>  **Важно для Internet Explorer:** Хотя второй параметр необязателен, старый браузер IE без него автоматически вставит в поле ввода текст `"undefined"`. Чтобы этого избежать, всегда передавайте вторым аргументом хотя бы пустую строку: `prompt("Вопрос", '');`.

---

## 3. confirm
Используется для получения простого согласия или несогласия (ответ формата Да / Нет).

* **Синтаксис:** `result = confirm(question);`
  * `question` — текст вопроса.
* **Что возвращает:**
  * **`true`**, если пользователь нажал кнопку «ОК».
  * **`false`**, если пользователь нажал кнопку «Отмена» или клавишу `Esc`.

```javascript
let isBoss = confirm("Ты здесь главный?");
alert(isBoss); // true, если нажата OK, и false в остальных случаях
```

---

## Ограничения встроенных окон
У простоты использования этих функций есть своя цена:
1. **Нельзя настроить внешний вид:** Дизайн, цвета, шрифты и кнопки окон полностью зависят от операционной системы и браузера. Изменить их средствами CSS или JS невозможно.
2. **Нельзя настроить положение:** Браузер сам решает, где показать окно (обычно строго по центру экрана).

---

## Итоговая таблица сравнения

| Функция | Назначение | Кнопки в окне | Результат при «ОК» | Результат при «Отмене» / Esc |
| :--- | :--- | :--- | :--- | :--- |
| **`alert`** | Показать сообщение | ОК | Ничего не возвращает | Ничего не возвращает |
| **`prompt`** | Запросить текст | ОК, Отмена | Строка с введенным текстом | `null` |

# Конспект: Преобразование типов в JavaScript

## 1. Строковое преобразование
Происходит при выводе данных или через `String(value)`. Преобразует примитивы очевидным образом: `true` -> `"true"`, `null` -> `"null"`.

```javascript
let value = String(true); // "true"
```

## 2. Численное преобразование
Происходит в математических выражениях или через `Number(value)`. Если строка содержит не только цифры, результатом будет `NaN`.

| Значение | Результат | Примечание |
| :--- | :--- | :--- |
| `undefined` | `NaN` | Отличается от null |
| `null` | `0` | |
| `true` / `false` | `1` / `0` | |
| `string` | Число / `NaN` | Пробелы по краям удаляются. Пустая строка -> `0`. |

```javascript
Number("   123   "); // 123
Number("123z");      // NaN
Number(null);        // 0
```

## 3. Логическое преобразование
Происходит в логических операциях или через `Boolean(value)`.

* **`false`** возвращают: `0`, `""` (пустая строка), `null`, `undefined`, `NaN`.
* **`true`** возвращают: все остальные значения, включая `"0"` и `" "` (строка с пробелом).

```javascript
Boolean("0"); // true
Boolean(" "); // true
Boolean("");  // false
```

# Конспект: Базовые операторы и математика в JavaScript

## 1. Терминология
* **Операнд (аргумент)** — то, к чему применяется оператор. В `5 * 2` операнды равны `5` и `2`.
* **Унарный оператор** — применяется к одному операнду. Пример: унарный минус `x = -x`.
* **Бинарный оператор** — применяется к двум операндам. Пример: бинарный минус `y - x`.

## 2. Математические операторы
* `+` Сложение
* `-` Вычитание
* `*` Умножение
* `/` Деление
* `%` Взятие остатка от деления (результат `5 % 2` равен `1`)
* `**` Возведение в степень (результат `2 ** 3` равен `8`, а `4 ** (1/2)` равен `2`)

## 3. Сложение и преобразование строк (бинарный `+`)
* Если хотя бы один операнд является строкой, второй автоматически приводится к строке.
* Другие арифметические операторы (`-`, `/`, `*`) всегда преобразуют операнды в числа.

```javascript
"1" + 2;     // "12"
2 + 2 + "1"; // "41" (вычисления идут слева направо: 4 + "1")
6 - "2";     // 4
"6" / "2";   // 3
```

## 4. Унарный `+` (приведение к числу)
* Применяется к одному операнду. Если это не число, преобразует его аналогично функции `Number(...)`.

```javascript
+true;           // 1
+"";             // 0
let a = "2", b = "3";
alert(+a + +b);  // 5 (унарные плюсы сработали до бинарного сложения)
```

## 5. Приоритет операторов
Определяет порядок выполнения. Операторы с большим номером приоритета выполняются раньше. Унарные операторы имеют более высокий приоритет, чем бинарные. Оператор присваивания `=` имеет очень низкий приоритет (`2`).

## 6. Присваивание
* **Возвращает значение:** Вызов `x = value` записывает `value` в `x` и возвращает его, что позволяет использовать присваивание внутри сложных выражений.
* **Цепочка присваиваний:** Работает справа налево.

```javascript
let c = 3 - (a = 2 + 1); // a = 3, c = 0
let x, y, z;
x = y = z = 2 + 2;        // x, y, z равны 4
```

## 7. Сокращенная арифметика с присваиванием
Комбинация арифметического оператора и присваивания (`+=`, `-=`, `*=`, `/=`, `**=`). Имеет приоритет как у обычного присваивания.

```javascript
let n = 2;
n += 5; // n = 7
n *= 3 + 5; // n *= 8 -> n = 56 (правая часть вычисляется первой)
```

## 8. Инкремент и декремент
Применяются только к переменным. Увеличивают (`++`) или уменьшают (`--`) значение на 1. Приоритет выше, чем у большинства арифметических операций.

* **Префиксная форма (`++counter`):** Сначала изменяет переменную, затем возвращает **новое** значение.
* **Постфиксная форма (`counter++`):** Изменяет переменную, но возвращает **старое** значение.

```javascript
let c1 = 1, c2 = 1;
let a = ++c1; // a = 2, c1 = 2
let b = c2++; // b = 1, c2 = 2
```

## 9. Побитовые операторы
Работают с 32-разрядными целыми числами на уровне двоичного представления: `&` (AND), `|` (OR), `^` (XOR), `~` (NOT), `<<` (левый сдвиг), `>>` (правый сдвиг), `>>>` (правый сдвиг с заполнением нулями).

## 10. Оператор «запятая»
Вычисляет несколько выражений, разделенных запятой `,`, но возвращает результат только последнего. Имеет самый низкий приоритет (ниже `=`), поэтому требует использования скобок.

```javascript
let res = (1 + 2, 3 + 4); // res = 7
let variant = 1 + 2, 3 + 4; // variant = 3 (из-за приоритетов: (variant = 3), 7)
```
# Конспект: Операторы сравнения в JavaScript

## 1. Базовые операторы
* `a > b`, `a < b` — Больше / меньше
* `a >= b`, `a <= b` — Больше/меньше или равно
* `a == b` — Равно (нестрогое)
* `a != b` — Не равно (нестрогое)

Все операторы сравнения возвращают логический тип: `true` или `false`.

```javascript
let result = 5 > 4; // true
```

## 2. Сравнение строк
Строки сравниваются посимвольно в лексикографическом (алфавитном) порядке на основе кодировки Unicode.
* Сравниваются первые символы строк. Если они равны, сравниваются вторые, и так далее.
* При разной длине большей считается более длинная строка (если их начала совпадают).
* Строчные буквы больше заглавных (`"a" > "A"`), так как их код в Unicode выше.

```javascript
"Коты" > "Кода";  // true (символ 'т' больше 'д')
"Сонный" > "Сон"; // true (первая строка длиннее)
```

## 3. Сравнение разных типов
При нестрогом сравнении разных типов JavaScript приводит их к числу. Логическое `true` становится `1`, а `false` становится `0`.

```javascript
"2" > 1;     // true ('2' становится числом 2)
"01" == 1;   // true ('01' становится числом 1)
true == 1;   // true
```

Парадокс нестрогого равенства:
```javascript
let a = 0;   // Boolean(a) -> false
let b = "0"; // Boolean(b) -> true
a == b;      // true! (оба операнда примаются к числу 0)
```

## 4. Строгое сравнение
Оператор строгого равенства `===` (и неравенства `!==`) проверяет равенство без приведения типов. Если типы разные, проверка возвращает `false`.

```javascript
0 == false;  // true (нестрогое, приводится к 0 == 0)
0 === false; // false (строгое, типы number и boolean разные)
```

## 5. Сравнение с null и undefined
* **При строгом равенстве `===`:** Не равны, так как у них разные типы данных.
* **При нестрогом равенстве `==`:** `null` и `undefined` равны друг другу (`null == undefined` дает `true`), но не равны ни какому другому значению в языке.
* **При математических сравнениях (`>`, `<`, `>=`, `<=`):** Значения приводятся к числам: `null` становится `0`, а `undefined` становится `NaN`.

Специфические случаи:
```javascript
// Случай с null (сравнения превращают null в 0, а равенство == нет)
null > 0;  // false
null == 0; // false
null >= 0; // true

// Случай с undefined (любое сравнение с NaN дает false)
undefined > 0;  // false
undefined < 0;  // false
undefined == 0; // false (undefined равен только null)
```

## Как избежать ошибок
1. Всегда используйте строгое равенство `===` вместо обычного `==`.
2. Не используйте операторы `>`, `<`, `>=`, `<=` с переменными, которые могут принимать значения `null` или `undefined`. Всегда делайте для них отдельную проверку в коде.

# Конспект: Условное ветвление в JavaScript

## 1. Инструкция if
Вычисляет условие в скобках. Если результат приводится к `true`, выполняет блок кода. Для нескольких инструкций используются фигурные скобки `{}`.

```javascript
if (year == 2015) {
  alert("Правильно!");
}
```

## 2. Логическое преобразование в условиях
Выражение внутри `if (...)` автоматически приводится к логическому типу (`Boolean`):
* **Falsy (ложные):** `0`, `""` (пустая строка), `null`, `undefined`, `NaN`. Код в таком блоке не выполнится.
* **Truthy (правдивые):** все остальные значения (включая любые непустые строки и числа, кроме `0`). Код выполнится всегда.

```javascript
if (0) { /* никогда не выполнится */ }
if (1) { /* выполнится всегда */ }
```

## 3. Блоки else и else if
* **`else`:** необязательный блок, выполняется, когда условие в `if` ложно.
* **`else if`:** используется для проверки последовательности нескольких альтернативных условий.

```javascript
if (year < 2015) {
  alert("Рано");
} else if (year > 2015) {
  alert("Поздно");
} else {
  alert("Верно!");
}
```

## 4. Тернарный оператор '?'
Единственный оператор в JavaScript, принимающий три аргумента. Используется для компактного получения значения на основе условия.

```javascript
let result = условие ? значение1 : значение2;
```

```javascript
// Рекомендуется использовать скобки для читаемости, хотя приоритет у '>' выше, чем у '?'
let accessAllowed = (age > 18) ? true : false;

// Оптимальный вариант без '?' (само сравнение уже возвращает true/false):
let accessAllowed = age > 18;
```

## 5. Несколько операторов '?' (цепочка)
Последовательность тернарных операторов заменяет конструкцию `if .. else if .. else`. Вычисления идут по порядку до первого истинного условия.

```javascript
let message = (age < 3) ? 'Малыш' :
  (age < 18) ? 'Привет' :
  (age < 100) ? 'Здравствуйте' :
  'Необычный возраст';
```

## Правило хорошего тона
Не используйте оператор `?` вместо `if` для простого выполнения инструкций без возврата значения. 
* Смысл `?` — **вернуть** то или иное значение.
* Смысл `if` — **выполнить** разные ветви кода.

```javascript
// Плохая практика (плохо читается):
(company == 'Netscape') ? alert('Верно!') : alert('Неправильно.');

// Хорошая практика:
if (company == 'Netscape') {
  alert('Верно!');
} else {
  alert('Неправильно.');
}
```
# Конспект: Логические операторы в JavaScript

В JavaScript логические операторы могут применяться к значениям любых типов и возвращать результаты также любого типа.

---

## 1. Оператор ИЛИ (`||`)

В традиционном понимании возвращает `true`, если хотя бы один из аргументов истинен.

### Расширенный алгоритм работы в JavaScript (Поиск первого истинного):
1. Вычисляет операнды слева направо.
2. Конвертирует каждый операнд в логическое значение.
3. Если результат `true`, останавливается и возвращает **исходное** значение этого операнда.
4. Если все операнды ложные (`falsy`), возвращает **последний** из них.

```javascript
alert( 1 || 0 );                  // 1
alert( null || 1 );               // 1
alert( undefined || null || 0 );  // 0 (все falsy, вернул последний)
```

### Практическое применение:
* **Выбор первого заполненного значения из списка:**
  ```javascript
  let firstName = "", lastName = "", nickName = "Суперкодер";
  alert( firstName || lastName || nickName || "Аноним"); // "Суперкодер"
  ```
* **Сокращенное вычисление (Short-circuit evaluation):** Если левый операнд `true`, правая часть даже не вычисляется.
  ```javascript
  true || alert("не сработает");
  false || alert("сработает");
  ```

---

## 2. Логическое присваивание ИЛИ (`||=`)

Синтаксис: `a ||= b`
Присваивает переменной `a` значение `b` только в том случае, если текущее значение `a` является ложным (`falsy`).

* **Эквивалент через сокращенное вычисление:** `a || (a = b)`
* **Эквивалент через `if`:**
  ```javascript
  if (!a) { a = b; }
  ```

### Примеры:
```javascript
let johnHasCar = false;
johnHasCar ||= "У Джона нет машины!"; // "У Джона нет машины!"

let manufacturer = "";
manufacturer ||= "Неизвестный производитель"; // "Неизвестный производитель"
```

---

## 3. Оператор И (`&&`)

В традиционном понимании возвращает `true`, только если оба аргумента истинны.

### Расширенный алгоритм работы в JavaScript (Поиск первого ложного):
1. Вычисляет операнды слева направо.
2. Конвертирует каждый операнд в логическое значение.
3. Если результат `false`, останавливается и возвращает **исходное** значение этого операнда.
4. Если все операнды истинные (`truthy`), возвращает **последний** из них.

```javascript
alert( 1 && 0 );         // 0
alert( null && 5 );      // null
alert( 1 && 2 && null ); // null
alert( 1 && 2 && 3 );    // 3 (все truthy, вернул последнее)
```

⚠️ **Правило стиля:** Не используйте `&&` как замену короткой записи `if`. Код `(x > 0) && alert('...')` хуже читается, чем `if (x > 0) alert('...')`.

---

## 4. Логическое присваивание И (`&&=`)

Синтаксис: `a &&= b`
Присваивает переменной `a` значение `b` только в том случае, если текущее значение `a` является истинным (`truthy`).

* **Эквивалент через сокращенное вычисление:** `a && (a = b)`
* **Эквивалент через `if`:**
  ```javascript
  if (a) { a = b; }
  ```

### Пример:
```javascript
let greeting = "Привет"; 
greeting &&= greeting + ", пользователь!";
alert(greeting); // "Привет, пользователь!"
```
*На практике используется редко.*

---

## 5. Оператор НЕ (`!`)

Приводит аргумент к логическому типу (`true`/`false`) и возвращает противоположное значение.

```javascript
alert( !true ); // false
alert( !0 );    // true
```

### Двойное НЕ (`!!`)
Используется для быстрого явного преобразования значения к логическому типу. Работает абсолютно аналогично функции `Boolean(value)`.
```javascript
alert( !!"строка" ); // true
alert( !!null );       // false
```

---

## Приоритет логических операторов

Порядок выполнения от высшего к низшему:
1. **`!`** (Наивысший приоритет, выполняется всегда первым)
2. **`&&`**
3. **`||`**
4. **`&&=`** / **`||=`** (Низший приоритет, на уровне обычного присваивания)
Выражение `a && b || c && d` будет вычисляться как `(a && b) || (c && d)`.

# Конспект: Операторы нулевого слияния и присваивания (`??`, `??=`)

Термин **«определено»** означает, что значение переменной не равняется ни `null`, ни `undefined`.

---

## 1. Оператор нулевого слияния (`??`)

Возвращает первый аргумент, если он определен, иначе возвращает второй аргумент.

* **Аналог через тернарный оператор:** 
  ```javascript
  result = (a !== null && a !== undefined) ? a : b;
  ```

### Основное назначение:
Установка значения по умолчанию для потенциально неопределенных переменных.

```javascript
let user;
alert(user ?? "Аноним"); // "Аноним" (user не определен)

let admin = "Иван";
alert(admin ?? "Аноним"); // "Иван" (admin определен)
```

Можно использовать цепочку из `??` для выбора первого определенного значения:
```javascript
let firstName = null, lastName = null, nickName = "Суперкодер";
alert(firstName ?? lastName ?? nickName ?? "Аноним"); // "Суперкодер"
```

---

## 2. Различие между `??` и `||`

* **`||`** возвращает первое **истинное** (`truthy`) значение.
* **`??`** возвращает первое **определенное** (не `null/undefined`) значение.

Оператор `||` не делает различий между `false`, `0`, пустой строкой `""` и `null/undefined` — они все для него ложные. Оператор `??` реагирует исключительно на `null` и `undefined`.

```javascript
let height = 0;

alert(height || 100); // 100 (0 — это falsy, возвращается альтернатива)
alert(height ?? 100); // 0 (0 — это определенное значение, оно и возвращается)
```

---

## 3. Приоритет и ограничения

* Приоритет `??` такой же, как и у `||` (низкий). Вычисляется до `=` и `?`, но после математических операторов (`+`, `*`).
* При использовании в вычислениях **необходимы круглые скобки**.

```javascript
let height = null, width = null;
let area = (height ?? 100) * (width ?? 50); // 5000
```
*Без скобок сначала выполнится умножение `100 * width`, что приведет к ошибке в логике.*

### Запрет на совместное использование:
Из соображений безопасности JavaScript запрещает совмещать `??` с `&&` или `||` напрямую без явного указания приоритета скобками.

```javascript
let x = 1 && 2 ?? 3;   // Синтаксическая ошибка!
let y = (1 && 2) ?? 3; // Работает без ошибок (y = 2)
```

---

## 4. Оператор нулевого присваивания (`??=`)

Присваивает левому операнду значение правого только в том случае, если левый операнд не определен (`null` или `undefined`).

* **Эквивалент через `if`:**
  ```javascript
  if (userAge === null || userAge === undefined) { userAge = 18; }
  ```

### Примеры:
```javascript
let userAge = null;
userAge ??= 18;
alert(userAge); // 18

let savedAge = 25;
savedAge ??= alert("не сработает"); // Правая часть игнорируется
alert(savedAge); // 25
```

# Конспект: Циклы while и for в JavaScript

## 1. Цикл «while»
Тело цикла выполняется до тех пор, пока условие `condition` истинно (`truthy`). Одно выполнение цикла называется **итерацией**.

```javascript
let i = 0;
while (i < 3) { 
  alert(i); // Выведет 0, затем 1, затем 2
  i++;
}
```

Условие автоматически приводится к логическому типу. `while (i)` работает так же, как `while (i != 0)`.
```javascript
let i = 3;
while (i) alert(i--); // 3, 2, 1 (скобки опущены для одной строки)
```

---

## 2. Цикл «do…while»
Сначала выполняет тело цикла один раз, а затем проверяет условие. Используется, когда тело цикла нужно выполнить **хотя бы раз**, даже если условие изначально ложно.

```javascript
let i = 0;
do {
  alert(i);
  i++;
} while (i < 3);
```

---

## 3. Цикл «for»
Наиболее распространенный цикл с управляющими параметрами.

```javascript
for (let i = 0; i < 3; i++) {
  alert(i); // 0, 1, 2
}
```

### Анатомия конструкции:
* **Начало (`let i = 0`):** Выполняется один раз при входе. Переменная `i` доступна только внутри цикла (встроенное объявление).
* **Условие (`i < 3`):** Проверяется перед каждой итерацией. Если `false`, цикл завершается.
* **Тело (`alert(i)`):** Выполняется, пока условие истинно.
* **Шаг (`i++`):** Выполняется после тела на каждой итерации перед проверкой условия.

### Пропуск частей:
Любую часть `for` можно пропустить, сохранив разделительные точки с запятой `;`.
```javascript
let i = 0;
for (; i < 3; i++) { ... } // Пропуск начала
for (; i < 3;) { alert(i++); } // Пропуск шага (аналог while)
for (;;) { ... } // Бесконечный цикл
```

---

## 4. Прерывание цикла: «break»
Директива `break` немедленно завершает выполнение цикла и передает управление на строку, следующую за ним.

```javascript
let sum = 0;
while (true) {
  let value = +prompt("Введите число", '');
  if (!value) break; // Выход из цикла, если ввод пуст или отменен
  sum += value;
}
alert('Сумма: ' + sum);
```

---

## 5. Переход к следующей итерации: «continue»
Директива `continue` прекращает текущую итерацию (пропускает оставшийся код в теле) и принудительно переходит к следующему шагу цикла. Позволяет избегать лишней вложенности фигурных скобок `if`.

```javascript
for (let i = 0; i < 10; i++) {
  if (i % 2 == 0) continue; // Пропускает четные числа
  alert(i); // Выведет 1, 3, 5, 7, 9
}
```

⚠️ **Важное ограничение:** Конструкции `break` и `continue` нельзя использовать внутри тернарного оператора `?`. Вызов `(i > 5) ? alert(i) : continue;` приведет к синтаксической ошибке.

---

## 6. Метки для break/continue
Метки используются для управления вложенными циклами. Метка имеет вид идентификатора с двоеточием перед циклом. Вызов `break/continue <ИмяМетки>` позволяет выйти из внешнего цикла или перешагнуть его итерацию.

```javascript
outer: for (let i = 0; i < 3; i++) {
  for (let j = 0; j < 3; j++) {
    let input = prompt(`Координаты (${i},${j})`, '');
    if (!input) break outer; // Прерывает внешний цикл с меткой outer
  }
}
alert('Готово!');
```

* **Ограничение:** Метки не заменяют оператор `goto`. Нельзя прыгнуть в произвольное место кода. Директива `break` должна находиться внутри маркированного блока кода, а `continue` — строго внутри цикла.

---

## Итоговая таблица

| Цикл | Проверка условия | Минимальное число итераций | Применение |
| :--- | :--- | :--- | :--- |
| **`while`** | Перед итерацией | `0` | Когда количество итераций заранее неизвестно |
| **`do..while`** | После итерации | `1` | Когда код тела должен сработать минимум один раз |
| **`for`** | Перед итерацией | `0` | Когда есть четкие параметры начала, шага и конца |

# Конспект: Конструкция "switch" в JavaScript

Конструкция `switch` заменяет собой сразу несколько `if` и предоставляет более наглядный способ сравнить выражение с несколькими вариантами.

---

## 1. Синтаксис и алгоритм работы

Конструкция включает в себя один или несколько блоков `case` и необязательный блок `default`.

```javascript
switch(x) {
  case 'value1':  // if (x === 'value1')
    ...
    [break]

  case 'value2':  // if (x === 'value2')
    ...
    [break]

  default:
    ...
    [break]
}
```

**Алгоритм:**
1. Переменная `x` проверяется на **строгое равенство (`===`)** значению первого `case`, затем второго и так далее.
2. При совпадении код начинает выполняться от соответствующей директивы `case` и идет вниз **до ближайшего `break`** или до конца `switch`.
3. Если ни один `case` не совпал, выполняется блок `default` (при его наличии).

---

## 2. Важность директивы break

Если `break` отсутствует, выполнение кода продолжается ниже по следующим блокам `case` и `default` **без проверки** их условий.

```javascript
let a = 4;

switch (a) {
  case 3:
    alert('Маловато');
  case 4:
    alert('В точку!'); // Выполнение начнется отсюда
  case 5:
    alert('Перебор');   // Тоже выполнится (нет break выше)
  default:
    alert('Нет значений'); // Тоже выполнится
}
```

---

## 3. Динамические выражения в аргументах

И `switch`, и `case` принимают в качестве аргументов любые выражения (вычисления), а не только фиксированные значения.

```javascript
let a = "1";
let b = 0;

switch (+a) { // Выражение преобразует строку в число 1
  case b + 1: // Выражение вычисляется в 1 (0 + 1)
    alert("Выполнится, так как 1 === 1");
    break;
}
```

---

## 4. Группировка «case»

Несколько блоков `case`, которые должны выполнять один и тот же код, можно объединять. Это работает благодаря «проваливанию» кода при отсутствии `break`.

```javascript
let a = 3;

switch (a) {
  case 4:
    alert('Правильно!');
    break;

  case 3: // Группировка: при совпадении с 3...
  case 5: // ...код провалится сюда и выполнит alert
    alert('Неправильно!');
    break;
}
```

---

## 5. Строгое сравнение типов данных

Сравнение аргумента `switch` с вариантами `case` всегда идет по правилам **строгого равенства (`===`)**. Разные типы данных не совпадут.

```javascript
let arg = prompt("Введите число?"); // prompt всегда возвращает строку, например, "3"

switch (arg) {
  case '2':
    alert('Два (строка)');
    break;

  case 3:
    alert('Никогда не выполнится!'); // Мертвый код: "3" !== 3
    break;

  default:
    alert('Неизвестное значение'); // Сработает этот блок
}
```

# Шпаргалка: Функции в JavaScript

## 1. Объявление и вызов
Функция — именованный блок кода для повторного использования.

```javascript
function showMessage() {
  alert('Всем привет!');
}
showMessage(); // Вызов
```

## 2. Область видимости
* **Локальные:** Объявлены внутри функции. Снаружи не видны.
* **Внешние (глобальные):** Объявлены снаружи. Функция может читать и изменять их, если внутри нет одноименной локальной переменной (перекрытие).

```javascript
let user = 'Вася';
function привет() {
  let user = 'Петя'; // Перекрывает внешнюю
  alert(user); // 'Петя'
}
```

## 3. Параметры и аргументы
* **Параметр** — переменная в описании функции. **Аргумент** — значение, передаваемое при вызове (копируется в параметр).
* Если аргумент не передан, параметр равен `undefined`.

### Значения по умолчанию
Задаются через `=` или оператор нулевого слияния `??` внутри тела. Вычисляются динамически в момент вызова.

```javascript
function msg(from, text = "пусто") { ... }
function count(val) { alert(val ?? "нет"); } // count(0) выведет 0
```

## 4. Возврат значения (`return`)
Прерывает функцию и возвращает результат. Пустой `return` или его отсутствие возвращают `undefined`.

```javascript
function sum(a, b) { return a + b; }
```
⚠️ **Важно:** Не переносите строку после `return`. Из-за автоподстановки `;` код `return \n value` превратится в пустой `return;`. Правильно: `return (value)`.

## 5. Чистый код (Бест-практис)
* **Имя — глагол с префиксом:** `show...` (показать), `get...` (вернуть), `calc...` (вычислить), `check...` (проверить на true/false).
* **Одна функция — одно действие.** Не смешивайте расчеты и вывод данных.
* **Самодокументируемость:** Дробите сложный код на мелкие функции вместо написания комментариев.

# Шпаргалка: Function Expression в JavaScript

В JavaScript функция — это не особая языковая структура, а специальный тип значения (действие).

---

## 1. Синтаксис: Declaration vs Expression

* **Function Declaration (Объявление):** Функция создается как отдельная конструкция в основном потоке кода. Имя обязательно.
* **Function Expression (Выражение):** Функция создается внутри другого выражения (например, присваивания). Может быть анонимной. Точка с запятой `;` на конце обязательна, так как завершает выражение присваивания.

```javascript
// Function Declaration
function sayHi() { alert("Привет"); }

// Function Expression
let sayHi = function() { alert("Привет"); };
```

---

## 2. Функция как значение и Колбэки

Функцию можно выводить как текст (покажет её исходный код), копировать в другие переменные или передавать как аргумент.
* **Колбэк (Callback / Обратный вызов):** Функция, которая передается в другую функцию в качестве аргумента с ожиданием, что она будет вызвана позже.

```javascript
function ask(question, yes, no) {
  if (confirm(question)) yes(); else no();
}

// Передача анонимных Function Expression в качестве колбэков
ask(
  "Вы согласны?",
  function() { alert("Да"); },
  function() { alert("Нет"); }
);
```

---

## 3. Ключевые различия

### А. Момент инициализации (Главное отличие)
* **Function Declaration:** Создается движком JS на стадии инициализации, *до* выполнения кода. Доступна во всем скрипте/блоке, её **можно вызывать до объявления**.
* **Function Expression:** Создается только тогда, когда поток выполнения доходит до нее. До этой строки функция не существует.

```javascript
sayHi(); // Работает!
function sayHi() { ... }

sayHiExpression(); // Ошибка!
let sayHiExpression = function() { ... };
```

### Б. Блочная область видимости (`use strict`)
В строгом режиме Function Declaration видна **только внутри фигурных скобок `{...}`**, в которых она объявлена. Наружу она не выходит.
* **Решение:** Чтобы использовать функцию условно (например, внутри `if`), нужно объявить переменную снаружи, а внутри присвоить ей анонимное выражение (Function Expression).

```javascript
let age = prompt("Возраст?", 18);
let welcome; // Объявляем снаружи

if (age < 18) {
  welcome = function() { alert("Привет!"); }; // Expression
} else {
  welcome = function() { alert("Здравствуйте!"); };
}

welcome(); // Работает везде
```

Тот же пример, сокращенный через тернарный оператор `?`:
```javascript
let welcome = (age < 18) ?
  function() { alert("Привет!"); } :
  function() { alert("Здравствуйте!"); };
```

---

## Итоговый выбор: что использовать?

1. **По умолчанию выбирайте Function Declaration.** Код становится более гибким (функции можно вызывать до объявления) и их легче визуально «ловить глазами».
2. **Используйте Function Expression только тогда, когда Declaration не подходит:** для условного создания функций внутри блоков (`if/else`) или при быстрой передаче анонимных колбэков по месту вызова.

# Шпаргалка: Стрелочные функции в JavaScript

**Стрелочные функции (arrow functions)** — ультралаконичный синтаксис для создания функций (в основном анонимных и колбэков).

---

## 1. Однострочные стрелочные функции

Если тело функции состоит из одного выражения, фигурные скобки `{}` и ключевое слово `return` **не требуются** — результат вычисляется и возвращается автоматически.

```javascript
// Базовый синтаксис
let func = (arg1, arg2) => expression;

// Пример: сложение двух чисел
let sum = (a, b) => a + b;
alert(sum(1, 2)); // 3
```

### Особенности работы с аргументами:
* **Один аргумент:** Круглые скобки вокруг параметра можно опустить.
* **Нет аргументов:** Круглые скобки обязаны быть пустыми.

```javascript
let double = n => n * 2;   // Один аргумент
let sayHi = () => alert("Привет!"); // Без аргументов
```

---

## 2. Динамическое создание

Как и Function Expression, стрелочные функции можно использовать внутри выражений, например, в тернарном операторе `?`:

```javascript
let age = prompt("Сколько Вам лет?", 18);

let welcome = (age < 18) ?
  () => alert('Привет!') :
  () => alert("Здравствуйте!");

welcome();
```

## 3. Многострочные стрелочные функции

Если для реализации логики требуется написать несколько инструкций, тело функции оборачивается в фигурные скобки `{}`. В этом случае автоматический возврат отключается, и **необходимо явно прописывать `return`**.

```javascript
let sum = (a, b) => {
  let result = a + b;
  return result; // Явный return обязателен внутри фигурных скобок
};
```

---

## Итоговая сводка

* **Без фигурных скобок:** `(...args) => выражение` — автоматически вычисляет и возвращает результат. Скобки опускаются, если аргумент ровно один: `n => n * 2`.
* **С фигурными скобками:** `(...args) => { инструкции; return значение; }` — позволяет писать полноценное тело функции из нескольких строк, но требует обязательного `return` для возврата данных.

# Финальная шпаргалка: Особенности JavaScript (Основы)

## 1. Структура кода и "use strict"
* **`;` (Точка с запятой):** Рекомендуется ставить после каждой инструкции. Автоподстановка перед `[` может не сработать и вызвать ошибку. После `{...}` (циклы, функции) `;` не требуется.
* **`"use strict";`:** Включает современный режим. Пишется на первой строке скрипта или функции. Классы включают его автоматически.

## 2. Переменные и 8 типов данных
* **Объявление:** `let` (переменная), `const` (неизменяемая), `var` (устаревшая).
* **Имена:** Буквы, цифры (не первыми), `$` и `_`. Динамическая типизация.
* **Типы:** `number`, `bigint`, `string`, `boolean`, `null` (пусто), `undefined` (не задано), `object`, `symbol`.
* **typeof:** `typeof null` -> `"object"` (ошибка в языке), `typeof function(){}` -> `"function"`.

## 3. Взаимодействие (Модальные окна)
* `alert(msg)` — вывод сообщения.
* `prompt(q, [default])` — ввод текста; возвращает строку или `null` при отмене.
* `confirm(q)` — вопрос Да/Нет; возвращает `true/false`.

## 4. Операторы и Сравнение
* **Арифметика:** `+ - * /`, `%` (остаток), `**` (степень). Бинарный `+` объединяет строки, если хотя бы один операнд — строка (`"1" + 2` -> `"12"`).
* **Приведение к числу:** Унарный `+` и нестрогое сравнение `==` приводят разные типы к числу (`0 == false` -> `true`). Исключение: `null == undefined` (равны только друг другу).
* **Строгое сравнение `===`:** Проверяет равенство без приведения типов (`0 === false` -> `false`).
* **Логические:** `||` (ищет первое *truthy*), `&&` (ищет первое *falsy*), `!` (инверсия/приведение к boolean). Работает ленивое вычисление.
* **Нулевое слияние `??`:** Ищет первое *определенное* значение (не `null` и не `undefined`). Полезно для `0` и `""`. Запрещено совмещать с `&&` и `||` без скобок.

## 5. Циклы и Ветвление
* **Циклы:** `while (cond)`, `do..while (cond)` (минимум 1 раз), `for (let i=0; i<10; i++)`. 
* Переменная `let` внутри `for` локальна. `break` выходят из цикла, `continue` — из итерации. `break/continue + метка` выходят из вложенных циклов.
* **Конструкция `switch(x)`:** Сравнивает `x` с `case` строго по `===`. 
⚠️ Результат `prompt` всегда строка: `case 18:` не сработает для ввода, нужен `case "18":`. Без `break` код провалится в следующие `case`.

## 6. Функции (3 вида создания)
Локальные переменные видны только в теле. Если нет `return`, функция возвращает `undefined`.

| Тип создания | Синтаксис | Особенности |
| :--- | :--- | :--- |
| **Function Declaration** | `function sum(a, b) { return a + b; }` | Создается до выполнения кода. Можно вызывать выше объявления. Блочная видимость. |
| **Function Expression** | `let sum = function(a, b) { return a + b; };` | Создается, когда поток дойдет до нее. Нужна `;` в конце. |
| **Стрелочные функции** | `let sum = (a, b) => a + b;`<br>`let double = n => n * 2;`<br>`let sayHi = () => alert();` | Короткая запись. Без `{}` авто-return. С `{}` нужен явный `return`. |
