# Введение в JavaScript

**JavaScript (JS)** — изначально создавался, чтобы «сделать веб-страницы живыми». Скрипты работают как простой текст без компиляции и не имеют отношения к Java.

###  Движки (Виртуальные машины)
JS выполняется специальной программой — движком (в браузере или на сервере).
- **V8** — Chrome, Opera, Edge.
- **SpiderMonkey** — Firefox.
- **Схема работы:** Чтение (парсинг) ➡️ Компиляция в машинный код ➡️ Запуск и оптимизация.

###  Возможности в браузере (Безопасный язык)
- **Можно:** изменять HTML/CSS, реагировать на клики/мышь, отправлять сетевые запросы (AJAX), работать с куками и `localStorage`.
- **Нельзя (ради безопасности):** 
  - Читать/писать файлы на жестком диске (без выбора пользователем).
  - Получать доступ к другим вкладкам/окнам разных сайтов (*Политика одинакового источника / Same Origin Policy*).
  - Управлять камерой/микрофоном без явного разрешения.

###  Уникальность JS
Единственная браузерная технология, которая объединяет:
1. Полную интеграцию с **HTML/CSS**.
2. Простоту реализации базовых вещей.
3. Поддержку **всеми браузерами** по умолчанию.

###  Языки «над» JavaScript (Транспиляция)
Код сторонних языков конвертируется в JS перед запуском в браузере:
- **TypeScript** (от Microsoft) и **Flow** (от Facebook) — добавляют строгую типизацию для больших систем.
- **CoffeeScript** — синтаксический сахар для лаконичности.
- **Dart** (от Google) — язык для мобильных приложений и веба.
- **Brython** — транспилирует Python в JS.

# Справочники и спецификации JS

###  Спецификация (ECMA-262)
- **Суть:** Официальный стандарт, определяющий язык JavaScript. Источник самой достоверной информации.
- **Черновик стандарта:** [tc39.es/ecma262](https://tc39.es/ecma262/) (обновляется ежегодно).
- **Новые фичи (Stage 3):** Предложения, которые скоро войдут в стандарт, находятся на [github.com/tc39/proposals](https://github.com/tc39/proposals).

###  Справочники
- **MDN (Mozilla):** Главный ежедневный справочник с примерами (функции, методы, объекты).
- **Лайфхак поиска:** Искать в Google через префикс `MDN [запрос]` (например, `MDN parseInt`).

###  Таблицы совместимости
Помогают узнать, какие возможности языка уже поддерживаются браузерами и движками:
- [caniuse.com](https://caniuse.com) — поддержка фич по отдельности (включая криптографию, HTML/CSS).
- [kangax.github.io/compat-table](https://kangax.github.io/compat-table) — огромная детальная таблица соответствия стандартам (ES6, ES2016+).

# Редакторы кода: Главное

Программисты используют два типа инструментов: **IDE** и **«лёгкие» редакторы**. Многие совмещают оба варианта.

## 1. IDE (Интегрированная среда разработки)
Работает на уровне **всего проекта** (загружает много данных, видит связи между всеми файлами). Includes автодополнение, Git, тесты.

* **Visual Studio Code** — кросс-платформенная, бесплатная.
* **WebStorm** — кросс-платформенная, бесплатная для некоммерческого использования.
* **Visual Studio** — мощная, платная (есть бесплатная версия Community), только для Windows. Отлично подходит для .NET.

## 2. «Лёгкие» редакторы
Менее мощные, но **очень быстрые**. Нужны для того, чтобы моментально открыть и отредактировать один файл. Границы размыты из-за плагинов.

* **Sublime Text** — кроссплатформенный, условно-бесплатный.
* **Notepad++** — только для Windows, бесплатный.
* **Vim / Emacs** — хорошие консольные варианты для тех, кто умеет ими пользоваться.

> **Итог:** Выбор индивидуален. Выбирайте инструмент под свои привычки, задачи и личные предпочтения.

# Консоль разработчика: Главное

Браузер по умолчанию скрывает ошибки в коде. Чтобы их увидеть и починить, используются встроенные **Инструменты разработки** (Developer tools или **DevTools**). Популярные лидеры среди программистов — **Chrome** и **Firefox**.

## Что можно делать в консоли
* **Смотреть ошибки** — они подсвечиваются красным цветом.
* **Искать место поломки** — справа от ошибки указана ссылка на файл и номер строки кода.
* **Запускать JS-команды** — писать код в строке после символа `>`.
* **Многострочный ввод** — чтобы перенести строку без запуска кода, используйте **Shift + Enter**.

## Как открыть DevTools

| Браузер | Windows / Linux | macOS | Особые условия |
| :--- | :--- | :--- | :--- |
| **Chrome / Firefox / Edge** | `F12` | `Cmd + Opt + J` | Открывается сразу |
| **Safari** | Не поддерживается | `Cmd + Opt + C` | Нужно включить чекбокс в *Настройки -> Продвинутые -> Показывать меню «Разработка»* |

> **Итог:** DevTools во всех браузерах работают примерно одинаково. Они позволяют находить ошибки, проверять переменные и выполнять JavaScript «на лету».

# Привет, мир!: Главное

Для изучения самого языка JavaScript нужна среда запуска. В учебнике используется **браузер** (это проще для онлайн-примеров), но на сервере скрипты запускаются иначе (например, командой `node my.js`).

## Тег <script>
Код JavaScript вставляется в любое место HTML-документа с помощью тега `<script>`. Браузер выполняет его автоматически.

```html
<script>
  alert('Привет, мир!');
</script>
```

### Устаревшая разметка (не использовать в новом коде)
* **Атрибут `type="..."`** (раньше писали `type="text/javascript"`). Сейчас не нужен. В современном HTML применяется только для модулей.
* **Атрибут `language="..."`**. Устарел, так как JavaScript является языком по умолчанию.
* **HTML-комментарии внутри скрипта** (`<!-- ... //-->`). Использовались 15+ лет назад для древних браузеров. Сейчас это признак старого кода.

## Внешние скрипты
Большой и сложный код выносят в отдельные `.js` файлы и подключают через атрибут `src`:

```html
<!-- Абсолютный или относительный путь -->
<script src="/js/script1.js"></script> 
<!-- Полный URL-адрес из сети -->
<script src="https://cloudflare.com"></script> 
```

### Плюсы внешних файлов
* **Кеширование** — браузер скачивает файл один раз и сохраняет его у себя. 
* **Скорость** — при переходе на другие страницы скрипт берется из кеша, что экономит трафик и ускоряет загрузку сайта.

### Важное ограничение
>  **Нельзя совмещать код и атрибут `src` в одном теге!** Код внутри тега будет полностью проигнорирован.

* **Не работает:**
  ```html
  <script src="file.js"> alert(1); </script>
  ```
* **Правильно (разбить на два тега):**
  ```html
  <script src="file.js"></script>
  <script> alert(1); </script>
  ```

> **Итог:** JS подключается тегом `<script>`. Внутрь пишется простой код, а для сложного используется `<script src="путь_к_файлу.js">`.

# Структура кода: Главное

Код на JavaScript состоит из инструкций и комментариев. Они определяют логику работы программы и помогают разработчикам понимать её структуру.

## 1. Инструкции
**Инструкции** — это команды, которые выполняют действия (например, `alert('Привет')`). 

* Каждую инструкцию принято писать на **новой строке**, чтобы код было легче читать.
* Инструкции разделяются **точкой с запятой** (`;`).

## 2. Точка с запятой и её автоматическая вставка
В большинстве случаев точку с запятой в конце строки можно опустить. JavaScript понимает перенос строки как «неявную» точку с запятой. 

### Когда перенос строки НЕ вставляет точку с запятой:
1. **Строка не завершена:** Если строка заканчивается на оператор (например, `+`), движок понимает, что выражение продолжается на следующей строке.
   ```javascript
   alert(3 +
   1
   + 2); // Выведет 6
   ```
2. **Опасные ситуации (ошибки):** Иногда JavaScript «забывает» поставить точку с запятой, что приводит к критическим ошибкам. Чаще всего это происходит перед квадратными скобками `[...]`.

* **Код с ошибкой:**
  ```javascript
  alert("Hello")
  [1, 2].forEach(alert);
  ```
  *Почему ломается?* Движок не ставит тут точку с запятой и видит это как одну строку: `alert('Hello')[1, 2].forEach(alert);`.

>  **Правило сообщества:** Всегда ставьте точку с запятой между инструкциями. Это безопаснее и защищает от труднонаходимых ошибок.

## 3. Комментарии
Комментарии нужны для описания кода. Движок JavaScript полностью игнорирует их при выполнении.

* **Однострочные:** Начинаются с `//`. Комментарием становится всё, что идет после этих символов до конца строки.
  ```javascript
  // Это отдельный комментарий
  alert('Привет'); // Это комментарий после инструкции
  ```
* **Многострочные:** Начинаются с `/*` и заканчиваются `*/`.
  ```javascript
  /* Этот код временно отключен
  alert('Привет');
  */
  ```

### Важные нюансы о комментариях
* **Вложенные комментарии запрещены!** Код вида `/* ... /* ... */ ... */` вызовет ошибку.
* **Горячие клавиши:** Для быстрой вставки используйте `Ctrl + /` (Windows) или `Cmd + /` (Mac).
* **Размер кода:** Комментарии не раздувают итоговый сайт. Перед выкатом на сервер специальные инструменты (минификаторы) автоматически удаляют их из кода.

> **Итог:** Пишите каждую инструкцию с новой строки, обязательно ставьте `;` в конце и не стесняйтесь оставлять комментарии для пояснения сложной логики.

# Строгий режим — "use strict": Главное

До 2009 года JavaScript развивался с полной обратной совместимостью, из-за чего в языке копились старые ошибки проектирования. В стандарте ECMAScript 5 (ES5) появились изменения, которые могли сломать старый код. Чтобы этого не произошло, новые правила сделали отключаемыми. Для их активации используется директива `"use strict"`.

## Директива «use strict»
Строка `"use strict";` (или `'use strict';`) переводит интерпретатор JavaScript в современный режим работы, где исправлены некоторые системные ошибки и действуют более строгие правила написания кода.

* **Где размещать:** Только в самом начале скрипта или в начале тела функции (для локального включения).
* **Над директивой** могут находиться исключительно комментарии. Любой исполняемый код перед ней аннулирует её действие.

Неправильно (строгий режим не включится):
```javascript
alert("Некоторый код");
"use strict"; 
// Директива проигнорирована, так как она не на первой строке
```

* **Необратимость:** Строгий режим нельзя отключить внутри скрипта. Директивы вроде "no use strict" не существует.

## Работа в консоли браузера
В консоли DevTools строгий режим по умолчанию выключен. Чтобы запустить код в строгом режиме, используйте перенос строки:

```javascript
'use strict'; // Нажмите Shift+Enter для переноса
// ...ваш код... // Нажмите Enter для запуска
```

Для старых браузеров используется обёртка в функцию:
```javascript
(function() {
  'use strict';
  // ...ваш код...
})();
```

## Всегда ли нужно писать «use strict»?
В современном JavaScript писать директиву вручную нужно не всегда:

* **Классы и модули** (продвинутые структуры языка) включают строгий режим автоматически по стандарту.
* **В обычном коде** (без классов/модулей) добавлять `"use strict";` в начало файлов по-прежнему обязательно.

> Итог: На этапе изучения языка всегда добавляйте `"use strict";` на первую строку своих скриптов, чтобы сразу писать качественный код без устаревших багов.

# Переменные и константы: Главное

Переменная — это именованное хранилище для данных в памяти компьютера. Она позволяет структурировать информацию в приложении.

## 1. Объявление и использование переменных
Для работы с переменными используются ключевые слова `let`, `const` и устаревшее `var`.

* **Ключевое слово `let`** — современный стандарт объявления изменяемых переменных.
  ```javascript
  let message = 'Hello!'; // Объявили переменную и записали значение
  message = 'World!';     // Значение изменено, старое удалено
  ```
* **Правило хорошего тона:** Объявляйте каждую переменную на новой строке. Варианты записи нескольких переменных через запятую в одну или несколько строк технически работают, но ухудшают читаемость.
* **Запрет повторного объявления:** Переменную с одним и тем же именем можно объявить через `let` только один раз. Повторный вызов `let message` вызовет ошибку `SyntaxError`.
* **Устаревшее ключевое слово `var`:** Почти то же самое, что и `let`, но объявляет переменные специфическим старым способом. В современном коде не используется.

### Присвоение без объявления
В старом JavaScript без использования `"use strict"` можно было создать переменную, просто присвоив ей значение (`num = 5`). В строгом режиме такой код вызовет ошибку `ReferenceError: num is not defined`.

## 2. Константы (`const`)
Если переменная не должна меняться, её объявляют с помощью ключевого слова `const`. Попытка перезаписать константу приведет к ошибке.

Разработчики разделяют константы на два типа по способу их именования:
1. **Константы времени компиляции (жесткие):** Их значения известны **до запуска** скрипта. Используются как псевдонимы для «жестко закодированных» значений. Пишутся **ЗАГЛАВНЫМИ_БУКВАМИ** через подчеркивание.
   ```javascript
   const COLOR_RED = "#F00";
   const COLOR_ORANGE = "#FF7F00";
   ```
2. **Константы времени выполнения:** Их значения вычисляются **в процессе работы** программы, но после этого больше не изменяются. Пишутся в стандартном **camelCase**.
   ```javascript
   const pageLoadTime = /* время загрузки страницы */;
   ```

## 3. Правила именования переменных
Правильный выбор имен — один из важнейших навыков разработчика. 

* **Ограничения языка:**
  * Разрешены только буквы, цифры, а также символы `$` и `_`.
  * Имя не может начинаться с цифры.
  * Нельзя использовать зарезервированные слова (`let`, `class`, `return`, `function`).
* **Регистрозависимость:** Переменные `apple` и `APPLE` — это две абсолютно разные переменные.
* **Язык и стиль:** Используется международный стандарт — английский язык и верблюжья нотация (`userName`, `shoppingCart`). Использование кириллицы разрешено технически, но не рекомендуется.

### Рекомендации по выбору имен:
* Делайте имена максимально описательными и лаконичными. 
* Избегайте бесполезных имен вроде `data` и `value`, а также коротких букв `a`, `b`, `c` (за редкими исключениями).
* Договаривайтесь с командой о терминах (если пользователь — это `user`, то пишите `currentUser`, а не `currentVisitor`).

## 4. Создание новых переменных против повторного использования
Нельзя использовать одну и ту же переменную для хранения совершенно разных по смыслу данных ради мнимой экономии. 

* Повторное использование переменных запутывает код и усложняет отладку.
* Дополнительная переменная — это польза. Современные браузеры и минификаторы отлично оптимизируют код, поэтому разделение данных по разным переменным никак не вредит производительности и даже помогает движку оптимизировать вычисления.

> Итог: 
> * `let` — для изменяемых данных, `const` — для неизменяемых.
> * Имена должны быть понятными, на английском языке, в стиле camelCase.
> * Под каждую новую задачу создавайте новую переменную.

# Типы данных: Главное

JavaScript является **динамически типизированным** языком программирования. Типы данных привязаны к самим значениям, а не к переменным. Одна и та же переменная может сначала хранить строку, а затем — число.

Всего в JavaScript существует **8 основных типов данных**: 7 примитивных и 1 сложный (объект).

---

## 1. Число (number)
Представляет как целые числа, так и числа с плавающей точкой (десятичные дроби).

* **Специальные числовые значения:**
  * `Infinity` — математическая бесконечность (∞). Она больше любого числа. Можно получить, например, при делении на ноль (`1 / 0`).
  * `-Infinity` — отрицательная бесконечность.
  * `NaN` (Not a Number) — вычислительная ошибка. Возникает при выполнении математически некорректной операции (например, `"не число" / 2`).

* **Свойства NaN и безопасность:**
  * **«Прилипчивость»:** Любая математическая операция с участием `NaN` всегда возвращает `NaN` (например, `NaN + 1`). Единственное исключение: `NaN ** 0` равно `1`.
  * **Безопасность вычислений:** Математика в JavaScript безопасна. Скрипт никогда не упадет с критической ошибкой из-за неверных расчетов. В худшем случае программа вернет `NaN`.

---

## 2. BigInt
Обычный тип `number` не может безопасно хранить целые числа за пределами диапазона от -(2⁵³-1) до (2⁵³-1). За этими границами JavaScript теряет точность.

* **Назначение:** `BigInt` нужен для работы с целыми числами произвольной длины без ограничений (используется в криптографии или точных таймстампах).
* **Создание:** Чтобы указать, что число относится к типу `BigInt`, в самый конец числового литерала добавляется символ `n`.
  ```javascript
  const bigInt = 1234567890123456789012345678901234567890n;
  ```
* **Поддержка:** Работает во всех современных браузерах, кроме устаревшего Internet Explorer.

---

## 3. Строка (string)
Текстовые данные всегда оборачиваются в кавычки одного из трех видов:

1. Двойные кавычки: `"Привет"`.
2. Одинарные кавычки: `'Привет'` (ничем не отличаются от двойных).
3. Обратные кавычки (бектики): \`Привет\` (обладают расширенными возможностями).

* **Особенность обратных кавычек:** Позволяют встраивать переменные и любые математические выражения внутрь строки с помощью конструкции `${...}`.
  ```javascript
  let name = "Иван";
  alert( `Привет, ${name}!` ); // Выведет: Привет, Иван!
  alert( `Результат: ${1 + 2}` ); // Выведет: Результат: 3
  ```
  Обычные кавычки такую функциональность не поддерживают.

* **Важно:** В JavaScript нет отдельного типа данных для одного одиночного символа (типа `char`). Любой текст относится исключительно к типу `string`.

---

## 4. Булевый тип (boolean)
Логический тип данных, который имеет всего два возможных значения:
* `true` — истина (да).
* `false` — ложь (нет).

Используется для хранения флагов состояния или результатов сравнения (`let isGreater = 4 > 1;`).

---

## 5. Значение «null»
Специальное значение, которое образует свой собственный отдельный тип.
* **Смысл:** В JavaScript `null` не является ссылкой на несуществующий объект. Это просто маркер, обозначающий «ничего», «пусто» или «значение неизвестно».
  ```javascript
  let age = null; // Возраст пока неизвестен
  ```

---

## 6. Значение «undefined»
Также образует свой собственный отдельный тип.
* **Смысл:** Означает, что «значение переменной не было присвоено». Если переменная просто объявлена через `let`, но в неё ничего не записали, её значением автоматически становится `undefined`.
  ```javascript
  let age;
  alert(age); // Выведет "undefined"
  ```
* **Рекомендация:** Не стоит вручную присваивать `age = undefined`. Для явного обнуления переменной всегда используйте `null`.

---

## 7. Объекты (object)
Этот тип данных стоит особняком. Все предыдущие типы называют **«примитивными»**, так как они хранят только одно простое значение. Внутри объектов хранятся **коллекции данных** и сложные комплексные структуры.

---

## 8. Символы (symbol)
Используется для создания уникальных идентификаторов внутри объектов.

---

## Оператор typeof
Используется для проверки того, какой тип данных находится внутри переменной. Возвращает результат в виде строки.

* **Синтаксис:** Может использоваться как обычный оператор (`typeof x`) или в форме функции (`typeof(x)`).
* **Приоритет:** Имеет очень высокий приоритет. При проверке выражений обязательны скобки, иначе проверится только первый элемент: `typeof (50 + " Квартир")`.

* **Результаты вызовов:**
  ```javascript
  typeof undefined   // "undefined"
  typeof 0           // "number"
  typeof 10n         // "bigint"
  typeof true        // "boolean"
  typeof "foo"       // "string"
  typeof Symbol("id")// "symbol"
  typeof Math        // "object"   (встроенный объект)
  typeof null        // "object"   (историческая ошибка в языке)
  typeof alert       // "function" (функции технически объекты, но выделяются)
  ```

* **Важные нюансы typeof:**
  1. `typeof null` возвращает `"object"` — это признанная ошибка в самом JavaScript, допущенная при его создании. Её оставили ради обратной совместимости. На самом деле `null` — это отдельный примитивный тип.
  2. `typeof alert` возвращает `"function"` — отдельных типов для функций нет (они являются разновидностью объектов), но оператор обрабатывает их по-особенному для удобства.

  # Взаимодействие: alert, prompt, confirm: Главное

Для взаимодействия с пользователем в браузере используются три встроенные функции: `alert`, `prompt` и `confirm`. 

Все они вызывают **модальные окна**. Это означает, что пока окно открыто, пользователь полностью заблокирован: он не может кликать по странице, нажимать кнопки или взаимодействовать с остальным интерфейсом сайта. Выполнение скрипта на это время также приостанавливается.

---

## 1. alert
Просто выводит информационное сообщение на экран и останавливает работу, пока пользователь не нажмет «ОК».

```javascript
alert("Hello");
```

---

## 2. prompt
Используется для получения текстовых данных от пользователя.

* **Синтаксис:** `result = prompt(title, [default]);`
  * `title` — текст вопроса, отображаемый в окне.
  * `default` — необязательный второй параметр, который задает начальное значение в поле ввода. Квадратные скобки `[...]` в документации всегда указывают на факультативность параметра.
* **Что возвращает:**
  * **Строку** с тем текстом, который ввел пользователь (если нажата кнопка «ОК»).
  * **`null`**, если пользователь отменил ввод (нажал кнопку «Отмена» или клавишу `Esc`).

```javascript
let age = prompt('Сколько тебе лет?', 100);
alert(`Тебе ${age} лет!`); // Выведет значение, либо null при отмене
```

>  **Важно для Internet Explorer:** Хотя второй параметр необязателен, старый браузер IE без него автоматически вставит в поле ввода текст `"undefined"`. Чтобы этого избежать, всегда передавайте вторым аргументом хотя бы пустую строку: `prompt("Вопрос", '');`.

---

## 3. confirm
Используется для получения простого согласия или несогласия (ответ формата Да / Нет).

* **Синтаксис:** `result = confirm(question);`
  * `question` — текст вопроса.
* **Что возвращает:**
  * **`true`**, если пользователь нажал кнопку «ОК».
  * **`false`**, если пользователь нажал кнопку «Отмена» или клавишу `Esc`.

```javascript
let isBoss = confirm("Ты здесь главный?");
alert(isBoss); // true, если нажата OK, и false в остальных случаях
```

---

## Ограничения встроенных окон
У простоты использования этих функций есть своя цена:
1. **Нельзя настроить внешний вид:** Дизайн, цвета, шрифты и кнопки окон полностью зависят от операционной системы и браузера. Изменить их средствами CSS или JS невозможно.
2. **Нельзя настроить положение:** Браузер сам решает, где показать окно (обычно строго по центру экрана).
